

# Linux File Permission Auditor

ابزاری برای بررسی مجوز دسترسی فایل‌ها و پوشه‌ها در سیستم‌عامل Linux.

برنامه یک مسیر را دریافت می‌کند، محتوای آن را به‌صورت بازگشتی بررسی می‌کند و مواردی را که برای تمام کاربران قابل نوشتن هستند، در یک گزارش نمایش می‌دهد.

## امکانات

- بررسی فایل‌ها و زیرپوشه‌ها
- شناسایی فایل‌های دارای مجوز نوشتن برای همه کاربران
- شناسایی پوشه‌های دارای مجوز نوشتن بدون Sticky Bit
- نمایش نوع فایل و سطح دسترسی
- شمارش موارد بررسی‌شده
- نمایش تعداد موارد مشکوک
- نادیده گرفتن Symbolic Linkها
- عدم تغییر فایل‌ها و مجوزهای سیستم

## فناوری‌های استفاده‌شده

- Python 3
- pathlib
- stat

تمام ماژول‌های استفاده‌شده بخشی از کتابخانه استاندارد Python هستند.

## پیش‌نیازها

- Python 3
- Linux

نیازی به نصب کتابخانه خارجی نیست.

## روش اجرا

در ترمینال وارد پوشه پروژه شوید:

```bash
python3 main.py
```

سپس مسیر پوشه موردنظر را وارد کنید.

برای مثال:

```text
/home/linux
```

## نمونه کاربرد

این ابزار برای بررسی اولیه مجوزهای فایل‌ها و پیدا کردن تنظیمات دسترسی بیش از حد باز در سیستم‌های Linux قابل استفاده است.

## محدودیت‌ها

- فقط مجوزهای مربوط به نوشتن برای سایر کاربران بررسی می‌شوند.
- مالکیت فایل‌ها و ACLها بررسی نمی‌شوند.
- Symbolic Linkها عمداً نادیده گرفته می‌شوند.
- این برنامه مجوزهای فایل‌ها را تغییر نمی‌دهد.
- نتیجه بررسی به دسترسی کاربر اجراکننده برنامه بستگی دارد.
- گزارش برنامه به‌تنهایی اثبات‌کننده وجود آسیب‌پذیری امنیتی نیست.

## هدف پروژه

تمرین کار با مجوزهای فایل در Linux، استفاده از pathlib و stat و ساخت یک ابزار کوچک برای بررسی اولیه تنظیمات دسترسی سیستم.
